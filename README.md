# نظام دعوات المناسبات بالباركود

نظام كامل لإدارة حفلات الزواج: تنشئ الحفل، تضيف المدعوين بأسمائهم وأرقامهم، يوصل لكل واحد رابط دعوة خاص، يوافق أو يعتذر، وإذا وافق يطلع له باركود يُمسح مرة واحدة فقط عند باب الحفل.

---

## خطوات النشر على Render

### ١. ارفع المشروع على GitHub
- افتح github.com وأنشئ مستودعًا جديدًا (Repository) باسم `wedding-invites` واجعله **Private**.
- ارفع كل ملفات المشروع فيه (اسحبها وأفلتها في صفحة "uploading an existing file").

### ٢. أنشئ قاعدة البيانات
- في render.com اضغط **New** ← **Postgres**.
- الاسم: `wedding-db` — الخطة: **Free** — اضغط Create.
- انتظر حتى تصبح الحالة Available، ثم انسخ قيمة **Internal Database URL**.

### ٣. أنشئ الخدمة
- اضغط **New** ← **Web Service** واختر مستودع GitHub الذي أنشأته.
- الإعدادات:
  - Runtime: **Node**
  - Build Command: `npm install`
  - Start Command: `npm start`
  - Plan: **Free**

### ٤. أضف متغيرات البيئة (Environment Variables)

| المفتاح | القيمة |
|---|---|
| `DATABASE_URL` | الرابط الذي نسخته من قاعدة البيانات |
| `ADMIN_PIN` | `282834` (أو أي رمز تختاره) |
| `SESSION_SECRET` | أي نص عشوائي طويل، ٤٠ حرفًا فأكثر |
| `NODE_ENV` | `production` |

### ٥. اضغط Create Web Service
خلال دقيقتين يعطيك رابطًا مثل `https://wedding-invites.onrender.com` — الجداول تُنشأ تلقائيًا أول تشغيل.

> **بديل أسرع:** الملف `render.yaml` موجود في المشروع. من Render اختر **New ← Blueprint** واختر المستودع، وسيُنشئ الخدمة وقاعدة البيانات معًا تلقائيًا. غيّر `ADMIN_PIN` بعدها إن أردت.

## طريقة الاستخدام

**أنت (صاحب النظام):** افتح الرابط الرئيسي، أدخل الرمز السري، أنشئ الحفل، ألصق المدعوين بالصيغة:
```
503667823 عبدالرحمن نسيم
0545276049 جهاد فيصل
0539416020 ابراهيم احمد
```
ثم اضغط على بطاقة أي مدعو لنسخ رابط دعوته أو إرسالها له مباشرة على واتساب.

**المدعو:** يفتح رابطه، يشوف صورة الدعوة واسمه واسم الحفل، ويضغط **موافق** فيطلع له الباركود، أو **غير موافق** فيُسجَّل اعتذاره.

**فريق الاستقبال:** أعطهم رابط الاستقبال فقط (`/s/...`) — يفتح شاشة كاميرا، ولا يصل منه أحد للوحة التحكم ولا لأرقام الجوالات.

---

## نقاط تقنية

- كل مدعو له توكن عشوائي غير قابل للتخمين — لا يمكن تزوير باركود.
- التحقق **ذرّي** على مستوى قاعدة البيانات: لو انمسح نفس الباركود من جهازين بنفس اللحظة، واحد فقط ينجح.
- الباركود لا يعمل إلا إذا وافق صاحبه على الحضور، ولا يعمل في حفل آخر.
- الرمز السري محفوظ كمتغير بيئة، وجلسة الدخول موقّعة بـ HMAC وتنتهي بعد ١٢ ساعة.
- الخطة المجانية في Render تُنيم الخدمة بعد خمول ١٥ دقيقة، فأول فتح بعدها يأخذ ٣٠ ثانية تقريبًا. قبل الحفل بنصف ساعة افتح الرابط مرة لتصحو الخدمة، أو رقِّ الخطة المدفوعة ليلة الحفل.
